# Galaga for PICO-8

A port of the Galaga clone to [PICO-8](https://www.lexaloffle.com/pico-8.php): a fantasy console with a 128 x 128 screen, 16 colours and 8192 tokens of Lua.

[**▶ Play it in your browser**](https://shadester.github.io/galagas/pico8/)

![Gameplay: the autoplay build with a tractor beam and a captured fighter](docs/gameplay.gif)

The rules are the rules of the PSP game (`../psp/game.c`, which follows the C64 game): `game.lua` is a line-by-line port of the Thumby Color version (`../thumby/Galaga/game.py`). A test runs the Lua code in PICO-8 next to the C original and compares the whole game state after every tick.

The game plays by the rules of the arcade Galaga (40 aliens, the arcade flight paths, dive scheduler and bombs; see `../ARCADE.md`). The start argument `c64` selects the rules of the C64 game (32 aliens) instead.

## Status

It runs in PICO-8 0.2.6b. The lockstep test passes in 6 scenarios with the arcade rules and 4 (`c64-*`) with the C64 rules. The cart has about 7000 of the 8192 tokens. The cart is `galaga.p8` (and `galaga.p8.png`, with the title picture as its label).

## Features

The same features as the other versions: 40-alien formation (32 with the C64 rules) with fly-in waves and dives, bosses that take two hits, tractor beam capture, rescue and dual fighter, challenge stages with a 10,000 bonus, a shots / hits / ratio screen after each stage, bonus ships, title picture, jingles and sound effects, and the hi-score (saved with `cartdata`).

What is different:

- The screen is 128 x 128. The game keeps the C64 coordinates, and the picture is stretched like on the Thumby Color: x by 0.4, y by 0.56. The sprites are not stretched.
- The HUD (score, lives, hi-score, stage) is in the top 14 rows.
- PICO-8 numbers are 16.16 fixed point. Score, hi-score and the random number generator keep a 32-bit integer in the raw bits of a number (see the top of `game.lua`), so the game is the same as in C.
- The game runs at 50 ticks a second, as on the C64: `_update60` skips one call in six.
- The PICO-8 pause menu pauses the game. The menu item "title screen" quits to the title screen (a new hi-score is kept).

## Controls

| PICO-8 | Action |
|---|---|
| LEFT / RIGHT | Move the ship |
| O or X | Fire, start the game |

## Run and test

```sh
pico8 -run galaga.p8                      # play (add -windowed 1 if it starts full screen)
pico8 -run galaga.p8 -p "autoplay stage=3"   # arguments: c64 autoplay forcecapture few stage=N lives=N diff=N shot=N rec=A gif=B
python3 tools/gen_paths.py                # paths.lua, from ../thumby/Galaga/paths_data.py
python3 tools/gen_arcade_p8.py             # arcade_data.lua and tests/trace.p8, from ../psp/arcade_data.h
python3 tools/gen_assets.py [preview.png] # galaga.p8: sprites, title picture, sound, the arcade flight paths
python3 tests/test_lockstep.py [ticks] [scenario ...]   # needs pico8 and cc; PICO8=path if pico8 is not on PATH
```

To make the `.p8.png`: `pico8 -export galaga.p8.png galaga.p8` (it fails if the cart has more than 8192 tokens).
To make the web page: `pico8 -export ../docs/pico8/index.html galaga.p8`, then change the `<title>` in it to "Galaga for PICO-8". GitHub Pages serves `docs/`.

## Source layout

| File | Contents |
|---|---|
| `game.lua` | The rules: a port of `game.py`. No drawing |
| `main.lua` | Input, drawing, sound, the hi-score, the start arguments |
| `galaga.p8` | The cart: includes the three Lua files, holds sprites, title picture and sound. Generated by `tools/gen_assets.py` |
| `paths.lua` | Generated: the flight paths of the C64 rules, one digit for each step |
| `arcade_data.lua` | Generated: the numbers of the arcade rules (slots, wave lists, tables), as strings. The 62 flight paths are a bit stream in the free map and sprite sheet memory (`tools/gen_arcade_p8.py`) |
| `tools/` | `gen_paths.py`, `gen_arcade_p8.py`, `p8_tokens.py` (token counter), `gen_assets.py` (sprite art from `../thumby/tools/gen_assets.py`, jingles from `../thumby/Galaga/jingles/`) |
| `tests/` | `test_lockstep.py` + `trace.p8` (made from `trace.lua`; headless PICO-8 against `c_trace_arcade.c`, and for the `c64-*` scenarios `../thumby/tests/c_trace.c`) |
